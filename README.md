# 议论文逐段精评

一个用于中文议论文和论证性论文审阅的 ChatGPT/Codex skill。它逐段、逐章和全文评分，检查证明责任、证据、推理、反例与结构，并把精简的问题和修改建议写进用户提供的 Word 副本批注。

## 使用

安装此 skill 后，上传 `.docx` 并说：

> 用「议论文逐段精评」审阅这篇文章，逐段逐章评分，检查全文论证，并在 Word 批注中写明问题和精简修改建议。

纯文本也可评审，但 Word 批注需要原始 `.docx`。评分是诊断工具，不代表任何考试的官方分数。具体量规和流程见 [SKILL.md](SKILL.md)。

## 文件

- `SKILL.md`：触发条件、评分量规和审阅流程
- `agents/openai.yaml`：技能界面元数据
